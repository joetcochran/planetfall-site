# Tools

Almost every problem in this project ended in a tool: a script, a test, a page or a written rule that stops the problem coming back. This page catalogues them, grouped by the work they serve. Each entry gives the path, what it is for, when it was born, with the commit, and why. Paths are relative to the `Planetfall/` project folder; files served by the site (`scene/`, `dashboard/`, `data/` and the `.html` pages) are under `wwwroot/`. Every script carries a header comment that says more. A few tools lived only in a session's scratch folder or in Claude Code itself; they are marked as not in the repository.
